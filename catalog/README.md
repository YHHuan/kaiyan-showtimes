# 發行／品牌片單與策展系列

`discovery.json` 是人工核對的可選分類，不是新的場次來源。現有爬蟲、每天兩次更新排程、電影歸戶、海報、購票連結和收藏格式均不變。建站不連線抓片單，也不呼叫 LLM。

## 第一版涵蓋範圍

- 海鵬：2026 官方片單中有明確詳細頁路徑與片長的 18 部；玻璃男孩、獨裁大明星的詳細頁當次都指向空路徑，因此暫不加入。不是完整歷年片單。
- A24：實境誘捕、開放性邀請、後座力。前兩部中文片名／導演／片長另由威秀官方介紹核對；後座力由海鵬與 A24 官方介紹核對。同片可屬多個品牌。A24 官網列名不等於全部由 A24 製作，也不等於台灣發行商。
- 誠品周日經典：2026/9/27 小王子、10/11 無法無天、10/18 男歡女愛，皆 11:00。幻之光詳細頁當次無法讀取，暫不硬配。
- 2026 女性影展／光點華山：只核對 OPENTIX「焦點影人#1」的 10/18 16:40、10/21 15:10，1 廳。時間來自官方公開頁的 JSON-LD `Event.startDate`；場地亦一致。合輯是一個節目，不拆成三個場次。

每筆保存官方 URL、核對日期與穩定 ID。系列公告可以存在而本站尚未取得相應場次；此時僅提供公告連結，不生成假場次、收藏場次或計入場次總數。不判定任何套票／系列券是否可用。

## 更新與核對

1. 讀取官方片單／電影／活動說明，核對中文片名、原文片名、導演與片長。按既有 Markdown-first 工作規範將文件轉為可讀文字，保留原始來源供追查。
2. 修改本檔旁的 JSON。`works[].id`、品牌及系列 ID 不隨排序或建站改變；不要存臨時 movie/row 索引。不同作品用不同 ID，不靠同名英文片名合併。
3. `sources` 說明作品身分證據；`brands[].url` 必須是該品牌官方片單／作品頁，且包含於 `sources`。只增加已核對的別名，不做子字串／模糊匹配。
4. 系列必須逐場填入 workId、戲院、日期、時間；有廳別、語言／版本、活動專屬 URL 時一併限縮。`bookingUrl` 是必須完全符合的活動入口，不可填一般影城首頁。不可把系列電影的所有一般場次都標成活動。
5. 核對日期只在實際重新查證後修改；不得因每日場次更新而自動刷新。刪除／改期時更新或撤回舊指定場次。可留歷史系列，介面會標示已結束。
6. 執行 `npm run check`、`npm test`，檢查 PR 後才整合。每日排程**不會自動擴充這份片單**；新增電影和系列需要另外核對。未來自動發現候選也應放在獨立程序，不能直接當成已核對資料。

## 比對／失效原則

中文片名精確正規化且版本相容，再由原文片名、片長（±3 分鐘）或導演佐證；有矛盾即拒絕。現有來源片長互相衝突也不貼標籤。僅中文片名沒有其他證據時維持未知。特定活動的精確 URL＋日期／時間／戲院／廳別可佐證節目，但不能覆蓋片名／版本等矛盾。同時多個入口無法分辨時不標系列。

`DATA.discovery` 是既有資料完成歸戶／壓縮後產生的附加欄位。載入失敗或 JSON 不合法會顯示分類不可用，一般場次照常建置；帶未知分類的網址不會偷偷變成查全部。測試直接驗證 catalog schema，因此壞掉的受版本控制片單會擋下 PR，日常建站則保持可用。

可用 `DISCOVERY_ENABLED=0 node build_site.mjs` 暫停分類，或在獲准後撤回功能 commit；不需遷移場次或收藏資料。此開關不會自行部署。分享網址使用 `?brand=haipeng`、`?brand=a24`、`?series=eslite-sunday-2026-q4`，其他日期／地區條件依舊適用。

## 影展檔期日曆

`festivals.json` 與 `discovery.json` 分離，只保存檔期、地區、官方入口，**不憑檔期推算放映場次**。
逐場資料由下列獨立抓取器提供，不進院線主資料集。
首版依 2026-10-05 讀到的官方公告：

| 影展 | 已核實期間 | 官方日期來源 |
|---|---|---|
| 臺中國際動畫影展 | 2026/10/03–10/10 | [TIAF 介紹](https://twtiaf.com/2026/about.php?cate=0&id=1) |
| 高雄電影節 | 2026/10/09–10/26 | [2026 雄影公告](https://www.kff.tw/content/2026kff-news018) |
| 台灣國際女性影展 | 2026/10/16–10/25 | [女性影展售票公告](https://www.wmw.org.tw/tw/title/1097) |
| 台北金馬影展 | 2026/11/06–11/22 | [2026 金馬公告](https://goldenhorse.org.tw/news/detail/2495) |

日期尾日包含在展期中，匯出 iCalendar 時才換成不含尾端的次日 `DTEND`。
活動公告不是每一場的保證，也不判斷售罄、套票或預售資格。`seriesId` 只連到既有核實系列，沒有對應時不產生查詢捷徑。

新增時使用每屆獨立、不重複的 `id`，保留官方 `sourceUrl`、`url`、`programUrl`、`checkedAt`、日期與城市。
不從往年推算今年、不把徵件期間當放映期間、不把頒獎典禮當影展全部展期。
只有重新閱讀並核實公告後才更新 `checkedAt`；這份名單不隨每天兩次場次排程自動補新影展。
改期或撤回公告時修改／撤回該筆，保留 Git 歷史；本機關注保留穩定 ID，不覆寫已退役 ID。

執行 `npm run check && npm test`；測試包含期間／時區／匯出、唯讀收藏、儲存失敗、手機排版及附加資料失效隔離。
一般建站故障時會產生附加頁退路並清除可讀的舊附加資料入口，主站 payload 保持不變；這不是跳過原站健康檢查。

## 官方逐場來源（獨立附加 feed）

`fetch/festivals.mjs` → `data/festivals/screenings.json` → 離線 `build_festivals.mjs` → `/festivals/data.json`。
資料在子目錄，院線的非遞迴 `data/*.json` 載入器與 `_status`／健康檢查均不讀取。

- [2026 TIAF 場次表](https://twtiaf.com/2026/schedule_list.php?cate=0)：從 `dayByDay` 讀影城、日期、廳、`data-films`、節目標題、片長及備註；核對年份及星期。`data-films` 可為多部合輯或空值。沒有公開固定場次 ID，使用本屆＋節目識別＋完整場地／日期／時間建立本地 ID，不做同名合併；合輯成員標題未在表中提供，不能保證搜尋到每一部短片。
- [2026 女性影展場次表](https://www.wmw.org.tw/tw/category/9)：只 `JSON.parse` 公開 `events`，不執行原站程式。`start` 從 **08:00** 起算，抓取時驗證 [官方時間元件](https://www.wmw.org.tw/assest/js/day.events.js) 的起算點；從日期表頭對應 `site24/site25` 與實際影廳。只收 `state:true`，多片合輯保持一整場。
- [高雄電影節官方場次表](https://www.kff.tw/schedule)：建立一次匿名工作階段，依公開前端請求 `/schedule/ajax`，讀 category **108** 的全展期日期，從 `auditoriums[].programs` 取得固定場次 ID。`_detail` 是重複預覽，不額外產生場次。保留官方結束時間；得獎場若尚無片單則清楚註記，不猜內容。不接 109 XR。
- 金馬仍只有已核實展期與官方入口。不能因沒有本站逐場資料就宣稱官方未公布。

上述來源於 2026-10-05 完整實抓驗證為 TIAF 54／雄影長短片 208／女性影展 66 場（包含已過日期），不是永久固定筆數或每個活動都涵蓋的保證。
只保留節目名稱、成員識別／片名、放映事實及短備註，不複製劇情長文、圖片、編輯帳號或原始 API 回應；匿名 Cookie／CSRF 不落地、不記錄。

轉場警告使用兩個人工核實的場地別名：女影「光點華山」→「光點華山電影館」（[官方場地／購票資訊](https://www.wmw.org.tw/tw/category/161)），
TIAF「iFG遠雄廣場威秀」→「台中iFG遠雄廣場威秀影城」（[官方戲院資訊](https://twtiaf.com/2026/transport.php?cate=2&id=2)）；只影響轉場判斷，不改來源名稱或院線資料，不合併兩邊場次。

抓取每請求限 12 秒／8MB，整體 180 秒，KFF 再限單來源約 90 秒，逐日串行間隔 300ms；workflow 步驟另限 4 分鐘並容許失敗。
每來源採整批成功才取代：空結果、重複 ID、欄位／日期錯誤、較上次少逾 40%，或任何一天失敗都保留舊整批及舊 `fetchedAt`，標記未核對。
開始前先原子寫入嘗試狀態，避免被中斷卻看似更新成功。首次無資料就顯示尚無可核對場次，不從院線或往年猜補。
公開來源資料仍可能本身有誤；這些檢查是防護，不是完整性或票量保證。

每屆 adapter/ID 明確綁定年份，展前 90 天至展後 7 天才抓；到期停止自動刷新，保留舊時間。
下一屆須重新核實檔期／來源與 schema 再加入，不能直接改年份重用舊快照。維護時先跑離線測試，再以
`node fetch/festivals.mjs --cache-dir /tmp/指定測試目錄` 驗證官方來源，勿為測試改寫正式快取。

新增影展逐場收藏只寫 `kaiyan.festival-sessions.v1`。固定 ID 的時間／廳別／合輯等內容改變，必須使用者重新確認；
複合 ID 的改期不自動推測等價，新場次與未查到的原收藏並存。與院線若重複收藏也不偷偷合併，撞期提示可供檢查。
來源失效或改期未確認的收藏不匯出。`.ics` 是一次性匯入，不提供持續訂閱／自動改期，也不存取 Google／Apple 帳號。
停用或撤回此功能不刪除任何收藏；恢復時仍可讀同一 key，原有院線收藏全程唯讀。
