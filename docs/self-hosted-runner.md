# 舊方案已停用：不把個人電腦當 self-hosted runner

本頁原先提出把 GitHub Actions 移到個人電腦來取得新光資料。
目前改採 [新光本機 JSON 補充](local-skcinemas.md)：只由 Windows／WSL 定時讀取公開場次、
上傳一份經檢查的 JSON；雲端負責建站、測試與部署，本機不接收遠端執行任務。

修正舊說明的幾點：

- 開眼已提供多日資料，不是只有當天；但仍可能缺少官方獨有的遠期預售。
- 本機連得上、雲端連線失敗，不足以單憑現有日誌斷定一定是防火牆封鎖 IP。
- 自有公開 repository 並不代表 self-hosted runner 就安全；不以「目前沒有外部 PR」作安全保證。
- 不需安裝 runner、常駐遠端服務或把 `runs-on` 改為 `self-hosted`。
- 本機關機時，雲端排程與開眼備援仍持續，並依原始時間排除過期快照。

沒有移除任何既有 Windows 任務、runner 或服務；新流程只建立具名、可停用的本機資料補抓任務。
